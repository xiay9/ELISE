# Third-party sources

- The ECF dataset originates from [NUSTM/MECPE](https://github.com/NUSTM/MECPE). Its upstream research-use terms continue to apply.
- MECAD originates from [MECAD-MECTEC](https://github.com/redifinition/MECAD-MECTEC); see [M3HG](https://github.com/redifinition/M3HG) for the corresponding research context.
- The fixed encoder implementation was extracted from the authors' PaceVer/PaceExt research code. Internal package names are retained for compatibility; no complete external baseline repository is bundled.
- RoBERTa and Qwen model weights are separate dependencies and are not included. Their original model licenses and usage terms apply. The verifier is [Qwen3.6-27B](https://huggingface.co/Qwen/Qwen3.6-27B).
- Runtime libraries retain their own licenses. This source release does not relicense third-party data, model weights or dependencies.
